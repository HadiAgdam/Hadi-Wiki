
# Install `Node.js`

React's development tools run on Node.js. Install it from [nodejs.org](https://nodejs.org/?utm_source=chatgpt.com).

After installation, open your VS Code terminal and run:

```
node -v
npm -v
```

Both commands should print version numbers.



# Create a project

In your terminal, navigate to wherever you keep your projects, then run:

```bash
npm create vite@latest my-react-app -- --template react
```

Next:
```bash
cd my-react-app
npm install
npm run dev
```
